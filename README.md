An AI-built entry for the make.fun bounty 'hidden-spec-cli-01-run-20261122'.

`mend` reads a patch (unified diff, search/replace, V4A or JSON), applies every edit
as one transaction and prints the resulting file changes. `main.ts` is the entrypoint
the grader runs; it uses only the Node 22 standard library.

## Run it

```sh
npm start
```

## Check it locally

```sh
npm test
npm run check
```

Both commands run from the repository root. `npm run check` wraps the site's check and prints a single
`pre-submit check: PASS`/`FAIL` verdict from the real exit code and summary row; the kit's
`verified 34 files` line on stderr is progress, not a failure. See PRE_SUBMIT.md for details.
